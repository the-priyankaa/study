INTRODUCTION TO ML
Q1 Machine Learning is a subset of which of the following? ▾
a) Data Science
b) Artificial Intelligence
c) Database Management
d) Operating Systems
ANSWER: B
Machine Learning is a subset of Artificial Intelligence (AI). It focuses on building systems that learn from data and make predictions or decisions. Deep Learning is further a subset of ML.
Q2 Which type of ML uses labeled data for training? ▾
a) Unsupervised Learning
b) Supervised Learning
c) Reinforcement Learning
d) Self-supervised Learning
ANSWER: B
Supervised Learning uses labeled datasets — the data comes with both inputs and their corresponding outputs. The model learns to map inputs to correct outputs. Examples: spam detection, price prediction.
Q3 Which of the following is an example of a Regression problem? ▾
a) Classifying email as spam or not
b) Predicting house price from its area
c) Grouping customers into segments
d) Detecting fraud — yes or no
ANSWER: B
Regression predicts a continuous numeric value. House price prediction is a classic regression example. Spam detection is classification; customer grouping is clustering.
NAIVE BAYES & K-NN
Q4 Why is Naive Bayes called "Naive"? ▾
a) It gives inaccurate results
b) It assumes all features are independent of each other
c) It requires very little data
d) It was invented by a naive scientist
ANSWER: B
The "naive" assumption is that all features are conditionally independent given the class label. This is often not true in real life, but the algorithm still works well in many applications like spam filtering and text classification.
Q5 Which Naive Bayes type is used when features follow a Normal distribution? ▾
a) Gaussian Naive Bayes
b) Bernoulli Naive Bayes
c) Multinomial Naive Bayes
d) Laplace Naive Bayes
ANSWER: A
Gaussian Naive Bayes is used when features are continuous and assumed to follow a Gaussian (Normal) distribution — a symmetric bell-shaped curve. Bernoulli is for binary features; Multinomial is for word counts.
Q6 In k-NN, what happens when k=1? ▾
a) Model underfits
b) Model may overfit — very sensitive to noise
c) Model becomes more generalized
d) No prediction is made
ANSWER: B
When k=1, the model assigns the class of the single nearest neighbor. This makes it extremely sensitive to noise and outliers, leading to overfitting. Larger k values give smoother decision boundaries.
Q7 Which distance measure is most commonly used in k-NN? ▾
a) Manhattan Distance
b) Euclidean Distance
c) Cosine Similarity
d) Hamming Distance
ANSWER: B
Euclidean Distance is the straight-line distance between two points and is the most commonly used metric in k-NN. Manhattan distance is also used, especially when data has many dimensions.

S3 Explain the steps of the Naive Bayes classification algorithm. ▾
ANSWER
Naive Bayes uses Bayes' Theorem: P(A|B) = P(B|A) × P(A) / P(B) Steps:
  • Step 1: Calculate Prior probability — P(class) for each class label from the training data.
  • Step 2: Calculate Likelihood — P(feature | class) for each feature-class combination.
  • Step 3: Apply Bayes' Formula — compute Posterior probability P(class | features).
  • Step 4: Predict the class with the highest posterior probability.
The word "Naive" means it assumes all features are independent, even when they are not. Despite this, it works well in spam filtering, text classification, and medical diagnosis.
S4 What is k-NN? Write the steps of the k-NN algorithm for classification. ▾
ANSWER
k-NN (k-Nearest Neighbors) classifies a new data point based on the majority class of its k nearest neighbors. It does not build an explicit model — it stores all training data.

Steps:
  • Choose the value of k (e.g., k=3 or k=5). Odd values preferred to avoid ties.
  • Calculate distance (usually Euclidean) between the new point and all training points.
  • Select the k points with the smallest distances.
  • Perform majority voting — the class that appears most among k neighbors is the prediction.
Applications: Recommendation systems, healthcare (disease prediction), fraud detection.
DECISION TREES & SVM
S5 What are the advantages and disadvantages of Decision Trees? ▾
ANSWER
Advantages:
  • Easy to understand and visualize — generates readable rules.
  • Handles both numerical and categorical data.
  • Non-parametric — no assumptions about data distribution.
  • Robust — not affected by outliers or missing values.
  • Fast prediction — cost is logarithmic in number of data points.
Disadvantages:
  • Overfitting — complex trees memorize training data. Fix: pruning, min samples per leaf.
  • Instability — small changes in data can produce a completely different tree.
  • Bias — if classes are imbalanced, biased trees result.
  • Learning the optimal tree is NP-complete.
S6 Explain the concept of Hyperplane, Margin, and Support Vectors in SVM. ▾
ANSWER
  • Hyperplane: A decision boundary that separates data points of different classes. Equation: W·X + b = 0. For 2 features it's a line; for 3 features it's a plane; for n features it's an n-1 dimensional plane.
  • Margin: The distance between the hyperplane and the nearest data points from each class. SVM maximizes this margin for better, more reliable classification. A wider margin = safer predictions.
  • Support Vectors: The data points closest to the hyperplane. They are the most important points — they decide where and how the hyperplane is drawn. Moving a support vector changes the hyperplane.
SVM goal: Find the hyperplane that maximizes the margin between classes.
S7 What is the Kernel Trick in SVM? Name 4 types of kernels. ▾
ANSWER
When data cannot be separated by a straight line in the original space (non-linear data), the Kernel Trick maps the data to a higher-dimensional space where it becomes linearly separable — without actually computing the transformation (saving computation).
K(xi, xj) = φ(xi)ᵀ φ(xj)
4 Types of Kernels:
  • Linear Kernel: For linearly separable data. K(x,z) = xᵀz
  • Polynomial Kernel: For curved boundaries. K(x,z) = (1 + xᵀz)^d
  • RBF / Gaussian Kernel: Most popular. Handles complex, circular data.
  • Sigmoid Kernel: Similar to neural network activation functions.
REGRESSION
S8 Write the Linear Regression equation and explain each term. What is the LMS update rule? ▾
ANSWER
Y = mX + c (Simple Linear Regression)
  • Y = Dependent variable (what we predict: salary, marks, price)
  • X = Independent variable (input: experience, hours, area)
  • m = Slope — how much Y changes when X increases by 1
  • c = Intercept — value of Y when X = 0
LMS (Least Mean Squares) Update Rule:
θj := θj + α × (y⁽ⁱ⁾ - hθ(x⁽ⁱ⁾)) × xj⁽ⁱ⁾
where α is the learning rate. The update is proportional to the prediction error — if prediction is close to actual, little update occurs; if error is large, bigger update happens.
S9 What is Logistic Regression? Explain the Sigmoid function and the decision boundary. ▾
ANSWER
Logistic Regression is a supervised classification algorithm used when output is categorical (0 or 1). It predicts the probability of an event.

Sigmoid Function:
σ(z) = 1 / (1 + e⁻ᶻ) where z = a₀ + a₁x
  • Output is always between 0 and 1
  • If σ(z) ≥ 0.5 → predict class 1 (Pass, Spam)
  • If σ(z) < 0.5 → predict class 0 (Fail, Not Spam)
Decision Boundary: The threshold (usually 0.5) where the model is equally likely to predict either class. At z=0, σ(z) = 0.5 exactly — the model is undecided.

UNSUPERVISED LEARNING
S11 Write the steps of the K-Means Clustering Algorithm. ▾
ANSWER
K-Means is an unsupervised, centroid-based clustering algorithm:
  • Step 1: Select K — choose the number of clusters to create.
  • Step 2: Initialize — randomly select K data points as initial centroids.
  • Step 3: Assignment — assign each data point to the nearest centroid to form K clusters.
  • Step 4: Update — calculate the mean of each cluster and move the centroid to that mean.
  • Step 5: Repeat Steps 3–4 until no data point changes its cluster assignment (convergence).
  • Step 6: Model is ready.
Goal: Minimize the sum of distances between each data point and its cluster centroid.
S12 What is PCA? What is the Curse of Dimensionality? ▾
ANSWER
PCA (Principal Component Analysis): A dimensionality reduction technique that converts n correlated variables into a smaller set of uncorrelated variables called Principal Components while maximizing variance preserved.
  • PC1 = the direction of maximum variance
  • PC2 = second highest variance, orthogonal to PC1
  • Each component is orthogonal (uncorrelated) to others
  • Limitation: Loses interpretability of original features
Curse of Dimensionality: As the number of features (dimensions) increases in a dataset:
  • Data becomes increasingly sparse
  • Distance measures lose meaning (distance concentration)
  • ML models require exponentially more data to train well
  • Computation time increases drastically
Solution: Apply dimensionality reduction (PCA, LDA, feature selection) before training.
EVALUATION & ENSEMBLE
S13 Define Accuracy, Precision, Recall, and F1-Score with formulas. ▾
ANSWER
Let TP=True Positive, TN=True Negative, FP=False Positive, FN=False Negative.
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Good when dataset is balanced.
Precision = TP / (TP + FP)
Important when False Positives are costly (e.g., spam filter — don't block real emails).
Recall = TP / (TP + FN)
Important when False Negatives are costly (e.g., cancer detection — don't miss a patient).
F1-Score = 2 × (Precision × Recall) / (Precision + Recall)
Best metric for imbalanced datasets — balances Precision and Recall.
S14 What is the Bias-Variance Tradeoff? How does it relate to overfitting and underfitting? ▾
ANSWER
  • Bias: Error from overly simple model — it misses patterns. High bias = underfitting.
  • Variance: Error from overly complex model — it memorizes noise. High variance = overfitting.
ConditionBiasVarianceResult
UnderfittingHighLowPoor performance on both train & test
OverfittingLowHighGreat on train, poor on test
Good ModelBalancedBalancedBest generalization
Goal: Find the sweet spot — low bias AND low variance — for the best generalization.
S15 What is Bagging? How does Random Forest use it? ▾
ANSWER
Bagging (Bootstrap Aggregation): An ensemble technique that reduces variance by training multiple models on different bootstrap samples of the original data (random sampling with replacement).

Random Forest uses Bagging as follows:
  • Step 1: Create multiple Bootstrap Datasets from original data (sampling with replacement).
  • Step 2: Train a randomized Decision Tree on each bootstrap dataset — each tree also uses a random subset of features at each split.
  • Step 3: Combine predictions — majority voting for classification, averaging for regression.
Random Forest reduces overfitting (compared to a single Decision Tree) while maintaining high accuracy.

ANSWER

S18 What is MLE (Maximum Likelihood Estimation)? Why is Log-Likelihood used instead of Likelihood? ▾
ANSWER
MLE: A method to estimate parameters of a model by finding parameter values that make the observed data most probable.
L(θ) = P(data | θ) → maximize this
Why Log-Likelihood instead of Likelihood:
  • Likelihood requires multiplying many probabilities (each between 0 and 1)
  • Product of many small numbers → underflow (too small for computers to store)
  • Log converts multiplication into addition: log(a×b) = log(a) + log(b)
  • Since log of probability is always negative → take the negative → minimize negative log-likelihood
Log Loss = -(1/n) Σ [y·log(ŷ) + (1-y)·log(1-ŷ)]
This is the standard loss function for Logistic Regression.
S19 What is Structural Risk Minimization? What is VC Dimension? ▾
ANSWER
VC Dimension: (Vapnik-Chervonenkis Dimension) — measures the complexity/capacity of a model. It is the maximum number of points a model can classify correctly in all possible arrangements (shatter). Example: A line in 2D has VC dimension = 3.

Structural Risk Minimization (SRM): To avoid overfitting, instead of minimizing only training error, SRM minimizes:
Total Risk = Empirical Risk + Model Complexity penalty
  • Empirical Risk: Training error
  • Model Complexity: Related to VC Dimension
SVM is based on the SRM principle — it finds the hyperplane that maximizes margin (minimizes complexity) while minimizing training error.
S20 What is Sparse Modeling and Estimation? What is LASSO? ▾
ANSWER
Sparse Modeling: Using only the most important features (few non-zero values) and ignoring/zeroing out the rest. From many variables, select only the ones that actually matter.

Estimation: Finding or predicting unknown model parameters using data. Example: finding the best m and c in Y = mX + c.

Sparse Estimation: Estimating model parameters while forcing many of them to zero — only important features remain.

LASSO (Least Absolute Shrinkage and Selection Operator):
  • Adds an L1 penalty to the loss function
  • Shrinks some coefficients to exactly zero — removes those features
  • Performs both regularization AND feature selection automatically
  • Example: From 20 house features, LASSO keeps only 3–4 important ones
ADDITIONAL SAQS
S21 What is information gain in a decision tree? How is it used for splitting? ▾
ANSWER
Information gain measures the reduction in entropy after a dataset is split on an attribute. The decision tree selects the attribute with the highest information gain at each node, meaning it picks the feature that best separates classes.
IG = Entropy(parent) − Σ weighted Entropy(children)
A higher information gain means the split has created more homogeneous (pure) child nodes, which is the goal at each step of tree construction.
S22 State the Naive Bayes assumption. Why is it called 'naive'? ▾
ANSWER
It assumes all features are conditionally independent given the class label. This is 'naive' because in real data, features are often correlated. Despite this, the model performs well in practice (e.g., spam filtering, text classification).
Naive Bayes computes P(class | features) ∝ P(class) × P(feature₁|class) × P(feature₂|class) × ... by multiplying individual feature likelihoods — which is only valid under the independence assumption.
S23 What is the difference between binary and multiclass classification? ▾
ANSWER
Binary classification predicts one of two possible classes (e.g., spam/not spam, pass/fail). Multiclass classification predicts one of three or more classes (e.g., digit recognition: 0–9, animal species identification).

Binary classification can be handled by algorithms like Logistic Regression (with Sigmoid) and SVM. Multiclass can be handled by Softmax Regression, Decision Trees, or One-vs-Rest strategies. Binary is a special case of multiclass.

S25 What is pruning in decision trees? ▾
ANSWER
Pruning removes branches that have little power in classifying instances, reducing overfitting. There are two types:
  • Pre-pruning: Stops tree growth early by setting constraints (max depth, min samples per leaf, min samples per split).
  • Post-pruning: Allows full tree growth, then removes branches that don't improve performance on a validation set.
Pruning improves generalization to unseen data by reducing model complexity and preventing the tree from memorizing noise in the training data.

L1 Explain the Decision Tree algorithm in detail. How is the best attribute selected? What is Entropy and Information Gain? Give a numerical example. ▾
DETAILED ANSWER
Decision Tree: A non-parametric supervised learning algorithm used for classification and regression. It has a tree-like structure with:
  • Root Node: Best attribute (most information gain)
  • Internal Nodes: Attributes/features tested
  • Leaf Nodes: Final class labels
  • Branches: Outcomes of attribute tests
Entropy (Measure of impurity/disorder):
Entropy(S) = -Σ pᵢ log₂(pᵢ)
where pᵢ = proportion of class i. Entropy = 0 means pure (all same class). Entropy = 1 means maximum disorder (50-50 split in binary). Information Gain:
IG(S, A) = Entropy(S) - Σ (|Sv|/|S|) × Entropy(Sv)
where Sv = subset of S when attribute A takes value v. We choose the attribute with the highest Information Gain as the split. Numerical Example (Tennis):
Suppose we have 14 examples: 9 Play=Yes, 5 Play=No.
Entropy(S) = -(9/14)log₂(9/14) - (5/14)log₂(5/14) = 0.940
For attribute "Outlook" (Sunny:5, Overcast:4, Rain:5):
  • Sunny: 2Yes, 3No → Entropy = 0.971
  • Overcast: 4Yes, 0No → Entropy = 0 (pure!)
  • Rain: 3Yes, 2No → Entropy = 0.971
IG(S, Outlook) = 0.940 - [(5/14)×0.971 + (4/14)×0 + (5/14)×0.971] = 0.246
Outlook gives the highest IG → it becomes the root node. Advantages: Simple, interpretable, handles missing values, non-parametric. Disadvantages: Overfitting (fix with pruning), sensitive to noisy data, unstable.
L2 Explain Support Vector Machines (SVM) in detail. Discuss Linear SVM, Non-linear SVM, Kernel Trick, and types of kernels. ▾
DETAILED ANSWER
SVM: A supervised ML algorithm for classification and regression that finds the best hyperplane to separate data classes by maximizing the margin. Key Concepts:
  • Hyperplane: W·X + b = 0 — decision boundary that separates classes. Shape depends on number of features: 2 features → line; 3 features → plane.
  • Margin: Distance between the hyperplane and the nearest points from each class. SVM maximizes this.
  • Support Vectors: Data points closest to the hyperplane. They determine the position of the hyperplane.
1. Linear SVM: Used when data is linearly separable (a straight line can separate classes). Two subtypes:
  • Hard Margin SVM: No point inside the margin allowed — works only for perfectly separable data.
  • Soft Margin SVM: Introduces slack variables (ξᵢ) to allow some misclassification — works for real-world messy data.
2. Non-linear SVM: When data cannot be separated by a straight line. Solution: the Kernel Trick. Kernel Trick: Maps data from input space to a higher-dimensional feature space where linear separation becomes possible. Avoids the actual transformation by computing an equivalent inner product:
K(xi, xj) = φ(xi)ᵀ φ(xj)
This avoids the computational cost of explicit transformation. Types of Kernels:
KernelFormulaUse Case
LinearK(x,z) = xᵀzLinearly separable data
PolynomialK(x,z) = (1 + xᵀz)^dCurved boundaries
RBF/GaussianK(x,z) = exp(-||x-z||²/2σ²)Complex, scattered data (most popular)
SigmoidK(x,z) = tanh(αxᵀz + c)Similar to neural networks
φ (phi) function: Maps input space (non-linear) → feature space (linear). Kernels compute the dot product in feature space without explicit mapping. Advantages of SVM: Works well in high dimensions, effective for non-linear data, memory efficient (only support vectors matter). Disadvantages: Slow with large datasets, sensitive to choice of kernel and hyperparameters.
L3 Explain Logistic Regression in detail. Discuss the Sigmoid function, Log Loss, MLE, multiclass classification (OvR and Softmax), and assumptions. ▾
DETAILED ANSWER
Logistic Regression: A supervised classification algorithm that predicts the probability of a binary class outcome (0 or 1) using the Sigmoid function. 1. Sigmoid Function:
σ(z) = 1 / (1 + e⁻ᶻ) where z = a₀ + a₁x
Always outputs a value between 0 and 1. Decision: if σ(z) ≥ 0.5 → class 1; else → class 0. Derivative of Sigmoid:
σ'(z) = σ(z) · (1 - σ(z))
Used in backpropagation/gradient descent. 2. Log Loss (Binary Cross-Entropy):
Log Loss = -(1/n) Σ [yᵢ·log(ŷᵢ) + (1-yᵢ)·log(1-ŷᵢ)]
  • If true label y=1: use -log(ŷ)
  • If true label y=0: use -log(1-ŷ)
3. Maximum Likelihood Estimation (MLE): Find parameters that maximize the probability of observed data. Multiplying probabilities → underflow → use log-likelihood → minimize negative log-likelihood = minimize log loss. 4. Multiclass Classification:
One-vs-Rest (OvR): For K classes, build K binary classifiers. Each classifies one class vs. all others. At prediction: pick class with highest confidence.
Softmax Regression: Uses Softmax function:
σ(zᵢ) = e^zᵢ / Σ e^zⱼ
Converts K logits to probability distribution. All probabilities sum to 1. Used when classes are mutually exclusive. 5. Assumptions of Logistic Regression:
  • Dependent variable is binary
  • Observations are independent
  • Linear relationship between independent variables and log-odds
  • No multicollinearity among predictors
  • Requires large sample size
Limitations: Assumes linear decision boundary, sensitive to outliers, poor with multicollinearity, struggles with high-dimensional data. Why called Logistic Regression? It first forms a linear equation z = w₁x₁ + ... + wₙxₙ + b (regression), then applies the logistic/sigmoid function. Despite classifying, it starts as regression — hence the name.

L4 Explain K-Means Clustering in detail with algorithm steps. How is it used in Image Segmentation? What are the stages of data preprocessing for K-Means? ▾
DETAILED ANSWER
K-Means Clustering: An unsupervised, centroid-based iterative algorithm that groups unlabeled data into K clusters such that each data point belongs to the cluster with the nearest centroid. Algorithm Steps:
  • Step 1: Select K — choose the number of clusters (e.g., K=3).
  • Step 2: Initialization — randomly select K data points as initial centroids.
  • Step 3: Assignment — assign each data point to the nearest centroid using Euclidean distance.
  • Step 4: Update — recalculate centroid as the mean of all points in its cluster.
  • Step 5: Repeat Steps 3–4 until no reassignment occurs (convergence).
  • Step 6: Model ready — each cluster is labeled with a cluster ID.
Objective: Minimize the Within-Cluster Sum of Squares (WCSS) — the total distance between each point and its centroid.
Image Segmentation using K-Means:
  • An image is treated as a set of pixels, each with color values (RGB).
  • K-Means groups pixels with similar colors into K segments.
  • Each segment gets a cluster ID — pixels in the same segment are colored uniformly.
  • Applications: Autonomous driving, medical imaging (tumor segmentation), satellite image analysis.
Data Preprocessing Stages for K-Means:
  • 1. Data Cleaning: Remove duplicates, handle errors, handle outliers and noise, remove unnecessary columns.
  • 2. Handle Missing Data: Impute or drop missing values.
  • 3. Data Integration: Merge data from multiple sources.
  • 4. Data Transformation: Feature construction, handle skewness, data scaling (important — K-Means is distance-based, so scale matters).
  • 5. Data Reduction: Remove correlated variables, feature selection, PCA.
Semi-supervised Clustering: Uses pair-wise constraints (must-link/cannot-link) to guide clustering. Two types:
  • Constraint-based: Uses labels/constraints to guide partitioning.
  • Distance-based: Adapts distance measure to satisfy constraints.
L5 Explain PCA in detail. What is Kernel PCA? Discuss other dimensionality reduction techniques (LDA, NMF, Low Variance Filter, Backward Feature Elimination). ▾
DETAILED ANSWER
PCA (Principal Component Analysis): A linear dimensionality reduction technique that transforms n correlated features into k uncorrelated principal components while maximizing variance preserved. How PCA works:
  • Compute covariance matrix of the data
  • Find eigenvectors and eigenvalues
  • Sort eigenvectors by eigenvalue (descending) — each eigenvector is a principal component
  • PC1 = direction of maximum variance; PC2 = second highest variance, orthogonal to PC1
  • Project data onto top k components
Limitation: PCA is linear — cannot capture non-linear patterns. Loses interpretability of original features. Sensitive to data scaling — must normalize first. Kernel PCA: Extends PCA to non-linear data by using a kernel function to first map data to a higher-dimensional space, then apply PCA in that space. Kernel types: Linear, Polynomial, Gaussian (RBF).
  • Advantages: Captures non-linear patterns, robust to outliers, versatile
  • Disadvantages: Computationally expensive, kernel selection is tricky

L6 Explain the evaluation methods and metrics for ML models. Discuss Train-Test Split, k-Fold Cross-Validation, all classification and regression metrics, and the Bias-Variance Tradeoff. ▾
DETAILED ANSWER
Evaluation Methods: 1. Train-Test Split: Divide data into training set (70–80%) and testing set (20–30%). Model learns from training; evaluated on unseen test data. Limitation: performance depends on the random split. 2. k-Fold Cross-Validation:
  • Divide data into k equal folds
  • Train on k-1 folds; test on remaining fold
  • Repeat k times — each fold serves as test set once
  • Final result = average of all k results
  • Most common: k=5 or k=10
  • More reliable than single train-test split; uses entire dataset
3. Stratified k-Fold: Used in classification — ensures each fold has the same class distribution as the original dataset. Important for imbalanced datasets. Classification Metrics:
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP) — when FP is costly
Recall = TP / (TP + FN) — when FN is costly
F1-Score = 2 × (Precision × Recall) / (Precision + Recall)
Regression Metrics:
MAE = (1/n) Σ |yᵢ - ŷᵢ| — average absolute error
MSE = (1/n) Σ (yᵢ - ŷᵢ)² — penalizes large errors more
RMSE = √MSE — same unit as target variable
R² = 1 - SSres/SStot — how well model explains variance (1 = perfect)
Bias-Variance Tradeoff:
  • Bias = error from oversimplified model (underfitting)
  • Variance = error from overcomplex model (overfitting)
  • As model complexity increases: bias decreases, variance increases
  • Goal: balanced model — low bias AND low variance
Macroaveraging vs Microaveraging (Multiclass):
  • Microaveraging: Average over all individual examples.
  • Macroaveraging: Calculate metric for each class separately, then average over classes. Better for imbalanced datasets.

Random Forest Algorithm:
  • Step 1: Create Bootstrap Datasets — randomly sample from original data (with replacement).

L8 What is Deep Learning? Explain CNN, RNN, and LSTM in detail with their applications. ▾
DETAILED ANSWER
Deep Learning: A subset of ML using multi-layered neural networks inspired by the human brain. It automatically learns hierarchical feature representations from raw data. Key Neural Network Components:
  • Weights: Parameters controlling strength of connections
  • Bias: Adjusts output of neurons
  • Activation Function: Introduces non-linearity (ReLU, Sigmoid, Tanh)
  • Backpropagation: Algorithm for learning by adjusting weights
1. CNN (Convolutional Neural Network):
  • Designed for image/visual data — excels at local pattern recognition
  • Uses filters/kernels (small 2D arrays) that slide over the image
  • Each filter detects specific features: edges → shapes → objects (hierarchical learning)
  • Convolution: filter × image patch = dot product → large if pattern matches, small if not
  • Layers: Convolutional → Pooling → Fully Connected
  • Applications: Image classification, object detection, face recognition, medical imaging
  • Why not standard NN? Full connections for images = too many parameters → overfitting + slow
2. RNN (Recurrent Neural Network):
  • Designed for sequential/time-series data
  • Has a hidden state — acts as "memory" of past inputs
  • Output at each step serves as input to the next step
  • Applications: NLP, speech recognition, time-series forecasting, machine translation
  • Limitation: Vanishing gradient problem — forgets long-term dependencies
3. LSTM (Long Short-Term Memory):
  • Improved version of RNN — solves the vanishing gradient problem
  • Uses gates (input, forget, output gates) to control what information to keep or discard
  • Can remember patterns over long sequences
  • Applications: Weather forecasting, speech recognition, language translation, stock prediction
4. GAN (Generative Adversarial Network): Two networks (Generator + Discriminator) competing — Generator creates fake data; Discriminator tries to detect it. Used for image generation, data augmentation. Deep Learning vs ML:

L9 Explain Statistical Learning Theory. Define Empirical Risk Minimization, VC Dimension, and Structural Risk Minimization. How does it relate to SVM? ▾
DETAILED ANSWER
Statistical Learning Theory (SLT): A theoretical framework that provides mathematical foundations for understanding how ML algorithms learn from data and generalize to unseen examples. Main Question: How can we ensure a model performs well on unseen data? This is called generalization. 1. Types of Risk:
  • Empirical Risk (Training Error): Error calculated on training data.
    R_emp = (1/n) Σ L(y, f(x))
  • True Risk (Expected Risk): Error on the entire real-world data distribution — cannot be calculated directly as we don't have all possible data.
    R_true = E[L(y, f(x))]
2. Empirical Risk Minimization (ERM): The principle of minimizing true risk by minimizing empirical risk on training data. Core idea: if training error is low and model is not too complex → test error should also be low. 3. Overfitting and Underfitting in SLT:
  • Overfitting: Very low training error but high test error — model too complex, memorized noise.
  • Underfitting: High training AND test error — model too simple, missed patterns.
  • Good Model: Balanced complexity → good generalization.
4. Model Capacity: Ability of model to fit different functions.
  • Linear model → low capacity
  • Neural network → high capacity
  • Too high → overfitting; too low → underfitting
5. VC Dimension: (Vapnik-Chervonenkis Dimension) — the maximum number of points a model can classify perfectly in all possible labeling arrangements (shatter). Example: A line in 2D can shatter 3 points → VC dim = 3. Higher VC dim = higher model capacity. 6. Structural Risk Minimization (SRM): Instead of minimizing only training error, minimize:
Total Risk = Empirical Risk + Model Complexity (VC-based penalty)
This balances training error and model complexity — avoiding overfitting. Connection to SVM: SVM is directly based on SRM. By maximizing the margin (keeping the classifier simple), SVM minimizes model complexity while minimizing training error. This gives SVM strong generalization guarantees. Importance of SLT: Provides mathematical tools to analyze generalization, design SVM, control overfitting, and choose appropriate model complexity. It forms the theoretical foundation of modern ML.

L11 Explain the working of a Decision Tree classifier with an example. Discuss entropy, information gain, and how splits are chosen. ▾
DETAILED ANSWER
A Decision Tree recursively splits data by choosing features that best separate classes. Entropy: H(S) = −Σ pᵢ log₂(pᵢ). For a pure set (all one class), entropy = 0. For a 50/50 split, entropy = 1. Information Gain: IG(S, A) = H(S) − Σ (|Sᵥ|/|S|) H(Sᵥ). The attribute with the highest IG is chosen as the split. Example — Classifying whether to play tennis: Based on attributes like Weather, Humidity, and Wind, the decision tree evaluates which attribute gives the highest information gain. If splitting on 'Outlook' gives the highest IG, it becomes the root node. Each branch then recursively splits on the remaining features. Stopping Criteria:
  • Maximum depth has been reached
  • All samples in a node belong to one class
  • Information gain = 0 (no benefit from splitting)
  • Number of samples in a node falls below minimum threshold
Handling Overfitting: Pruning prevents overfitting by removing low-significance branches. Decision trees are highly interpretable but prone to overfitting without proper regularization like pruning, setting max depth, or requiring minimum samples per leaf.
Decision trees form the foundation of powerful ensemble methods like Random Forest and Gradient Boosting.
L12 Compare Naive Bayes and Logistic Regression as binary classifiers. When would you prefer one over the other? ▾
DETAILED ANSWER
Naive Bayes: A generative model based on Bayes' theorem. It assumes conditional independence of features and computes P(class|features) via P(features|class) × P(class). It is very fast and works well with small data and text classification. Logistic Regression: A discriminative model that directly models P(Y=1|X) = σ(wᵀx + b) using the sigmoid function. Parameters are learned via gradient descent or maximum likelihood estimation. Key Differences:

TypeGenerativeDiscriminative

Prefer Naive Bayes for:
  • Text classification / spam filtering (high-dimensional sparse data)
  • Small datasets
  • Real-time inference where speed is critical
Prefer Logistic Regression for:

  • When the independence assumption of Naive Bayes is clearly violated
In practice, both are strong baselines. Logistic Regression often outperforms Naive Bayes when sufficient data is available, but Naive Bayes is unbeatable for speed and simplicity in high-dimensional text problems.
