MODULE 1 — REAL WORLD AI & RATIONALITY
S1 What is a Rational Agent? List the four types of AI agents. ▾
ANSWER
Rational Agent: An agent that acts to maximize its expected performance measure based on its percept history and built-in knowledge.

Four Types of AI Agents:
1. Simple Reflex Agent — Acts only on current percept (if-then rules).
2. Model-Based Reflex Agent — Maintains internal state to handle partial observability.
3. Goal-Based Agent — Takes actions to achieve specific goals.
4. Utility-Based Agent — Maximizes a utility function for best outcome among multiple goals.
S2 Explain the PEAS framework with an example. ▾
ANSWER
PEAS describes an agent's task environment:

• Performance Measure — How success is evaluated
• Environment — Where the agent operates
• Actuators — Output mechanisms
• Sensors — Input mechanisms

Example — Self-Driving Car:
• P: Safe driving, reaching destination, fuel efficiency
• E: Roads, traffic, pedestrians, weather
• A: Steering, accelerator, brakes, horn
• S: Cameras, GPS, LIDAR, speedometer
MODULE 2 — SEARCH ALGORITHMS
S3 Compare BFS and DFS in terms of completeness, optimality, time, and space complexity. ▾
ANSWER
BFS (Breadth-First Search):
• Completeness: Yes (if b is finite)
• Optimality: Yes (if all costs equal)
• Time: O(b^d)
• Space: O(b^d) — stores all nodes at depth d

DFS (Depth-First Search):
• Completeness: No (may loop in infinite spaces)
• Optimality: No
• Time: O(b^m)
• Space: O(bm) — only stores current path

Where b = branching factor, d = depth of solution, m = max depth.
S4 What is Uniform Cost Search? When is it preferred over BFS? ▾
ANSWER
Uniform Cost Search (UCS) expands the node with the lowest cumulative path cost g(n) using a priority queue. It always finds the optimal (least-cost) path.

When to prefer UCS over BFS:
UCS is preferred when step costs are NOT equal. BFS finds the shallowest solution (optimal only if all step costs are equal), while UCS finds the lowest-cost solution regardless of depth.

Example: In a city map where roads have different distances, UCS finds the shortest path, not just the path with fewest roads.
S5 What is Alpha-Beta Pruning? How does it improve Minimax? ▾
ANSWER
Minimax is a decision rule used in two-player games where MAX maximizes the score and MIN minimizes it. It explores the entire game tree.

Alpha-Beta Pruning improves Minimax by eliminating branches that cannot affect the final decision:
• Alpha (α) — best value MAX can guarantee (starts at −∞)
• Beta (β) — best value MIN can guarantee (starts at +∞)
• A branch is pruned when α ≥ β

Benefit: Reduces time complexity from O(b^m) to O(b^(m/2)), effectively doubling the search depth for the same computation.

Knowledge Representation (KR) is the field of AI dedicated to representing information about the world in a form that a computer system can use to solve complex tasks like diagnosing medical conditions or understanding natural language.

Four Types of Knowledge:
1. Declarative — Facts ("The sky is blue")
2. Procedural — How to do things ("Steps to solve an equation")
3. Meta-Knowledge — Knowledge about knowledge ("I know that I don't know X")
4. Heuristic — Rules of thumb ("If fever > 38°C, consider infection")
S7 Differentiate between Propositional Logic and First Order Predicate Logic. ▾
ANSWER
Propositional Logic:
• Deals with propositions (true/false statements)
• Cannot express relationships between objects
• Example: P = "It is raining", Q = "Roads are wet"
• Rule: P → Q

First Order Predicate Logic (FOPL):
• Deals with objects, predicates, and quantifiers
• Can express relationships and properties
• Uses ∀ (for all) and ∃ (there exists)
• Example: ∀x [Human(x) → Mortal(x)]

FOPL is far more expressive and is the basis of most knowledge representation systems.
MODULE 4 — DEEP LEARNING & NEURAL NETWORKS
S8 What is an ANN? Describe its basic structure. ▾
ANSWER
Artificial Neural Network (ANN) is a computing model inspired by biological neural networks in the brain.

Structure:
1. Input Layer — Receives raw input features (e.g., pixels, numbers)
2. Hidden Layer(s) — Performs transformations using weights and activation functions
3. Output Layer — Produces the final result (class, value)

Each neuron computes: output = activation(Σ(wᵢxᵢ) + bias)

Learning: Weights are adjusted via backpropagation and gradient descent to minimize the loss function.
S9 What is the difference between CNN and RNN? ▾
ANSWER
CNN (Convolutional Neural Network):
• Best for spatial data (images, video)
• Uses convolutional filters to detect local features
• Layers: Convolution → Pooling → Fully Connected
• Applications: Image classification, object detection

RNN (Recurrent Neural Network):
• Best for sequential/temporal data (text, speech, time series)
• Has feedback loops — output of one step is input to next
• Maintains "memory" of previous inputs
• Applications: Machine translation, speech recognition, text generation

MODULE 1 — REAL WORLD AI & RATIONALITY
L1 Explain the concept of Intelligent Agents in AI. Describe all types of agents with examples, and explain the properties of task environments (PEAS + 6 properties). ▾
DETAILED ANSWER
1. What is an Intelligent Agent?
An intelligent agent is anything that perceives its environment through sensors and acts upon it through actuators. It maps percept sequences to actions to maximize its performance measure.

2. Types of Agents
• Simple Reflex Agent: Uses condition-action rules (if percept → action). No memory. Works only in fully observable environments. Example: thermostat.
• Model-Based Reflex Agent: Maintains an internal model of the world for partial observability. Updates state based on percept history. Example: robot vacuum with memory.
• Goal-Based Agent: Has goals to achieve. Plans sequences of actions. Uses search and planning. Example: GPS navigation system.
• Utility-Based Agent: Has a utility function to choose the BEST action among many goal-achieving options. Example: self-driving car that balances speed, safety, and fuel.
• Learning Agent: Improves performance over time. Has performance element, critic, learning element, and problem generator.

3. PEAS Framework
Performance Measure, Environment, Actuators, Sensors. Used to specify an agent's task environment. Example for medical diagnostic agent: P=correct diagnosis, E=patient data/hospital, A=display recommendations, S=patient symptoms input.

4. Six Properties of Task Environments
• Fully vs Partially Observable: Can agent access complete state? (Fully: chess; Partially: poker)
• Deterministic vs Stochastic: Is next state fully determined? (Det: chess; Stoch: weather)
• Episodic vs Sequential: Do past actions affect current? (Episodic: spam filter; Seq: chess)
• Static vs Dynamic: Does environment change while agent thinks? (Static: crossword; Dynamic: taxi)
• Discrete vs Continuous: Finite or infinite percepts/actions? (Discrete: chess; Continuous: driving)
• Single vs Multi-Agent: One agent or many? (Single: puzzle; Multi: chess vs opponent)
MODULE 2 — SEARCH ALGORITHMS
L2 Explain all uninformed search strategies (BFS, DFS, UCS, Iterative Deepening) in detail with complexity analysis and comparison. ▾
DETAILED ANSWER
1. Breadth-First Search (BFS)
Explores all nodes level by level using a FIFO queue.
✓ Complete | ✓ Optimal (equal costs) | Time: O(b^d) | Space: O(b^d)
Best when: solution is at shallow depth, memory is abundant.

2. Depth-First Search (DFS)
Explores as deep as possible using a LIFO stack (or recursion).
✗ Not complete (infinite paths) | ✗ Not optimal | Time: O(b^m) | Space: O(bm)
Best when: memory is limited, solution is at deep level.

3. Uniform Cost Search (UCS)
Expands node with lowest cumulative cost g(n) using a priority queue.
✓ Complete | ✓ Optimal | Time: O(b^(1+⌊C*/ε⌋)) | Space: same as time
Best when: step costs vary. Equivalent to BFS when costs are equal.

4. Iterative Deepening DFS (IDDFS)
Repeatedly applies DFS with increasing depth limits (0, 1, 2, …).
✓ Complete | ✓ Optimal (equal costs) | Time: O(b^d) | Space: O(bd)
Best of both worlds: BFS's completeness + DFS's memory efficiency.

5. Comparison Summary
• BFS: Complete✓ Optimal✓ Space=High
• DFS: Complete✗ Optimal✗ Space=Low
• UCS: Complete✓ Optimal✓ Space=High
• IDDFS: Complete✓ Optimal✓ Space=Low ← Best uninformed
L3 Explain the Minimax algorithm with Alpha-Beta Pruning. Give a detailed example with a game tree. ▾
DETAILED ANSWER
1. Minimax Algorithm
Minimax is a recursive algorithm used for two-player zero-sum games (like Chess, Tic-Tac-Toe). MAX player tries to maximize the score; MIN player tries to minimize it.

Algorithm:
• If terminal state: return utility value
• If MAX's turn: return max(minimax(children))
• If MIN's turn: return min(minimax(children))

Time: O(b^m) | Space: O(bm)

2. Alpha-Beta Pruning
Optimization of Minimax that prunes branches that cannot affect the final decision.

• α (alpha) = best value MAX can guarantee so far (initially −∞)
• β (beta) = best value MIN can guarantee so far (initially +∞)
• Prune when: α ≥ β

At a MAX node: update α = max(α, value); if α ≥ β → prune remaining children
At a MIN node: update β = min(β, value); if α ≥ β → prune remaining children

3. Example Trace
Game tree with values at leaf nodes [3, 5, 2, 9, 1, 7, 4, 8]:
• Minimax explores ALL 8 nodes → result = 3
• Alpha-Beta prunes subtrees where value ≤ current α or ≥ current β
• Same result (3) with fewer nodes evaluated
Benefit: Best case O(b^(m/2)) — doubles effective search depth!

4. Applications
• Chess engines (Deep Blue used Minimax with Alpha-Beta)
• Tic-Tac-Toe solvers
• Checkers, Go (with modifications)
MODULE 3 — KNOWLEDGE REPRESENTATION
L4 What is Knowledge Representation? Explain different types of knowledge and representation techniques in detail. ▾
DETAILED ANSWER
1. What is Knowledge?
Knowledge is information + context + reasoning ability. In AI, knowledge must be represented in a formal, machine-readable way to enable reasoning, inference, and problem-solving.

2. Types of Knowledge
• Declarative: Facts about the world. "Delhi is the capital of India."
• Procedural: How to do something. "Algorithm to sort an array."
• Meta-Knowledge: Knowledge about knowledge. "I know that I don't know Y."
• Heuristic: Rules of thumb from experience. "If patient has fever + cough → test for flu."
• Structural: Knowledge about relationships. "Heart is part of circulatory system."

3. KR Techniques
• Logical Representation: Propositional Logic, First Order Predicate Logic (FOPL). Precise and formal. Example: ∀x [Dog(x) → Animal(x)]
• Semantic Networks: Graph-based, nodes = concepts, edges = relationships. Easy visualization. Example: "Canary IS-A Bird, Bird HAS wings."
• Frames: Data structures for stereotyped situations. Similar to OOP classes. Example: Frame for "Car" with slots: color, speed, fuel.
• Production Rules: IF-THEN rules. Used in Expert Systems. Example: IF temperature > 100°C THEN boiling = true.
• Ontologies: Formal representation of knowledge as a hierarchy of concepts within a domain.

4. Requirements of a Good KR System
• Representational Adequacy — Can represent needed knowledge
• Inferential Adequacy — Can derive new knowledge
• Inferential Efficiency — Can do so in reasonable time
• Acquisitional Efficiency — Easy to update/add knowledge
MODULE 4 — DEEP LEARNING & NEURAL NETWORKS
L5 Explain Deep Learning, ANN, CNN, and RNN in detail with architectures, working, and applications. ▾
DETAILED ANSWER
1. Deep Learning
A subfield of ML where neural networks with many hidden layers (deep networks) automatically learn hierarchical feature representations. Key advantage: No manual feature engineering. Requires large data and GPU computing.

2. Artificial Neural Network (ANN)
Inspired by: Biological neurons in the brain.
Structure: Input Layer → Hidden Layers → Output Layer
Neuron formula: y = activation(Σwᵢxᵢ + b)
Common Activations: Sigmoid (0-1), ReLU (max(0,x)), Tanh (−1 to 1), Softmax (multi-class)
Training: Forward pass → compute loss → Backpropagation → weight update (gradient descent)
Applications: Classification, regression, pattern recognition

3. CNN (Convolutional Neural Network)
Best for: Image, video, spatial data
Key Layers:
• Convolutional Layer: Applies filters to detect edges, textures, shapes
• Pooling Layer: Down-samples spatial dimensions (Max Pooling, Avg Pooling)
• Fully Connected Layer: Final classification
Why CNN for images: Parameter sharing + local connectivity → fewer parameters, translation invariant
Famous models: LeNet, AlexNet, VGG, ResNet
Applications: Image classification, face recognition, medical imaging

4. RNN (Recurrent Neural Network)
Best for: Sequential, time-series data
Key feature: Hidden state hₜ = f(Whh·hₜ₋₁ + Wxh·xₜ) — memory of past inputs
Problem: Vanishing gradient for long sequences
Solutions: LSTM (Long Short-Term Memory) and GRU (Gated Recurrent Unit)
LSTM gates: Forget gate, Input gate, Output gate
Applications: Text generation, machine translation, speech recognition, sentiment analysis

5. Comparison
• ANN: General purpose, tabular/flat data
• CNN: Spatial data (images), local feature detection
• RNN/LSTM: Sequential data, temporal dependencies
MODULE 5 — EXPERT SYSTEMS
L6 What is an Expert System? Explain its architecture, components, working (forward & backward chaining), advantages, limitations, and real-world applications in detail. ▾
DETAILED ANSWER
1. What is an Expert System?
An Expert System (ES) is an AI program that simulates the decision-making ability of a human expert in a specific domain. It uses a knowledge base and inference engine to solve problems that require expert knowledge.

2. Architecture / Components
• Knowledge Base: Stores domain knowledge as IF-THEN rules and facts. Example: IF fever > 38°C AND sore throat THEN diagnosis = flu
• Inference Engine: The "brain" — applies rules to facts to derive conclusions. Uses forward or backward chaining.
• Working Memory: Temporary storage for current session facts
• User Interface: Allows natural language interaction between user and system
• Explanation Facility: WHY a question is asked / HOW a conclusion was reached
• Knowledge Acquisition Facility: Interface for domain experts to add knowledge

3. Forward Chaining (Data-Driven)
Starts from known facts, applies rules, derives new facts until goal is reached.
Process: Facts → Rules → New Facts → … → Conclusion
Example: Known: Fever=Yes, Cough=Yes → Rule: Fever+Cough → Suspect Flu → Rule: Suspect Flu + Test Positive → Diagnose Flu
Used when: All data is available upfront, exploring possible outcomes.

4. Backward Chaining (Goal-Driven)
Starts from a goal/hypothesis and works backward to find supporting facts.
Process: Goal → Sub-goals → … → Known Facts
Example: Goal: Is patient diabetic? → Need: blood sugar > 200? → Ask user for blood sugar reading
Used when: Specific goal needs to be proved/disproved.

5. Advantages
• Available 24/7, consistent decisions
• Can explain reasoning (unlike most ML models)
• Captures and preserves expert knowledge
• Handles incomplete information

6. Limitations
• Knowledge acquisition bottleneck (extracting expert knowledge is hard)
• Cannot learn from experience (unlike ML)
• Limited to narrow domain
• Maintenance is costly as rules grow

7. Famous Real-World Expert Systems
• MYCIN (1970s): Blood infection diagnosis — recommended antibiotics
• DENDRAL: Chemical structure analysis — mass spectrometry
• XCON/R1 (DEC): Computer configuration — saved millions annually
• CADUCEUS: Internal medicine diagnosis
• Modern: Tax advisory systems, loan approval systems, medical diagnosis apps
