INTRODUCTION TO AI
Q1 What is Artificial Intelligence? Give a definition and 3 real-world examples. ▾
ANSWER
Definition: AI is the field of computer science that aims to build machines capable of performing tasks that typically require human intelligence — such as reasoning, learning, perception, and decision-making.

Real-World Examples:
  • Virtual assistants (Siri, Alexa, Google Assistant) using NLP
  • Autonomous vehicles using computer vision and planning
  • Recommendation systems (Netflix, YouTube) using collaborative filtering
Q2 Explain the Turing Test and its significance in AI. ▾
ANSWER
Proposed by Alan Turing in 1950, the Turing Test evaluates whether a machine can exhibit intelligent behavior indistinguishable from a human.

Setup: A human evaluator converses via text with both a human and a machine. If the evaluator cannot reliably tell them apart, the machine passes.

Significance: It shifted the question from "Can machines think?" to "Can machines behave intelligently?" — establishing a practical benchmark for AI.

Q5 What is A* Search? Explain the role of the heuristic function h(n). ▾
ANSWER
A* Search is an informed (heuristic) search algorithm that combines actual cost and estimated cost:
f(n) = g(n) + h(n)
  • g(n): Actual cost from start to node n
  • h(n): Heuristic estimate from n to goal
Heuristic h(n) guides the search toward the goal. For A* to be optimal, h(n) must be:
  • Admissible: Never overestimates the true cost
  • Consistent: h(n) ≤ cost(n, n') + h(n') for every successor n'
A* is both complete and optimal when h(n) is admissible.
Q6 Explain Minimax algorithm with Alpha-Beta Pruning. Where is it used? ▾
ANSWER
Minimax is a recursive algorithm for two-player zero-sum games (e.g., Chess, Tic-Tac-Toe).
  • MAX player tries to maximize the score
  • MIN player tries to minimize the score
  • The algorithm explores the full game tree and backtracks values
Alpha-Beta Pruning optimizes Minimax by cutting off branches that cannot influence the final decision:
  • Alpha: Best value MAX can guarantee so far
  • Beta: Best value MIN can guarantee so far
  • If alpha ≥ beta, prune the branch
Alpha-Beta pruning produces the same result as full Minimax but examines fewer nodes — saving computation time.
KNOWLEDGE REPRESENTATION & LOGIC
Q7 What is Propositional Logic? Explain its syntax, semantics, and limitations. ▾
ANSWER
Propositional Logic (PL) deals with propositions (statements that are True or False) and logical connectives.

Syntax — Logical Connectives:
  • ¬ (NOT), ∧ (AND), ∨ (OR), → (IMPLIES), ↔ (IFF)
Semantics: Determined by truth tables — each connective defines how the truth value of a compound sentence depends on its components.

Limitations:
  • Cannot express relationships between objects ("All humans are mortal")
  • No quantifiers (∀, ∃)
  • Not expressive enough for complex knowledge representation
Q8 What is First-Order Logic (FOL)? Compare it with Propositional Logic. ▾
ANSWER
First-Order Logic (FOL) extends propositional logic by adding:
  • Objects: Things in the world (e.g., John, House)
  • Predicates: Properties or relations (e.g., IsMortal(x), Loves(x,y))
  • Quantifiers: ∀ (for all), ∃ (there exists)
∀x (Human(x) → Mortal(x)) — "All humans are mortal"

EXPERT SYSTEMS & PLANNING
Q11 What is an Expert System? Describe its components and give 2 examples. ▾
ANSWER
Expert System: An AI program that emulates the decision-making ability of a human expert in a specific domain.

Components:
  • Knowledge Base: Contains facts and rules from domain experts
  • Inference Engine: Applies logical rules to derive conclusions from the knowledge base
  • User Interface: Allows users to query the system and receive answers
Examples:
  • MYCIN — medical diagnosis system for bacterial infections
  • DENDRAL — chemical analysis to identify molecular structure
Q12 What is STRIPS? Explain how it is used in AI planning. ▾
ANSWER
STRIPS (Stanford Research Institute Problem Solver) is a classical planning framework in AI.

Components of a STRIPS problem:
  • Initial State: Description of the world at the start
  • Goal State: Desired conditions to achieve
  • Actions: Each action has preconditions, add-list, and delete-list
Example — Blocks World:
  • Action: Move(block A, from B, to C)
  • Precondition: Clear(A), Clear(C), On(A,B)
  • Add: On(A,C), Clear(B)
  • Delete: On(A,B), Clear(C)
The planner searches for a sequence of actions that transforms the initial state into the goal state.
NEURAL NETWORKS & DEEP LEARNING
Q13 Explain the structure of a Perceptron and how it learns using the Perceptron Learning Rule. ▾
ANSWER
Perceptron: The simplest neural network — a single-layer binary classifier.

Structure:
  • Inputs x₁, x₂, …, xₙ with corresponding weights w₁, w₂, …, wₙ
  • Bias term b
  • Activation: if Σ(wᵢxᵢ) + b ≥ 0 → output 1; else output 0
Learning Rule:
wᵢ := wᵢ + α × (target - predicted) × xᵢ
  • If prediction is correct → no update
  • If prediction is wrong → adjust weights toward the correct answer
Limitation: A single perceptron can only solve linearly separable problems (cannot solve XOR).
Q14 What is Backpropagation? Explain the steps in training a multi-layer neural network. ▾
ANSWER
Backpropagation is the algorithm used to train multi-layer neural networks by computing gradients of the loss with respect to each weight.

Steps:
  • Forward Pass: Input flows through the network layer by layer to produce an output
  • Compute Loss: Compare output with target using a loss function (e.g., MSE, Cross-Entropy)
  • Backward Pass: Apply the chain rule to compute gradients — starting from output layer back to input
  • Weight Update: Adjust each weight using gradient descent:
    w := w - α × ∂L/∂w
This process is repeated for many epochs until the loss converges.
Q15 What are Transformers? Why are they replacing RNNs in modern AI? ▾
ANSWER
Transformers are a neural network architecture introduced in 2017 ("Attention Is All You Need") that rely entirely on the Self-Attention Mechanism.

Key innovations:
  • Self-Attention: Every token attends to every other token — captures long-range dependencies in parallel
  • No recurrence: Processes all tokens simultaneously (not sequentially)
  • Positional Encoding: Adds position information since there's no inherent order
Why replacing RNNs:
  • Much faster training (parallelizable)
  • Better at capturing long-range dependencies
  • No vanishing gradient problem
  • Scales well with data and compute — enabling models like GPT, BERT, and LLMs
