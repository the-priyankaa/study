UNIT 1: PYTHON BASICS
Q1 What is Python? Who developed it and when? ▾
A) Low-level language by James Gosling (1995)
B) High-level interpreted language by Guido van Rossum (1991)
C) Compiled language by Dennis Ritchie (1972)
D) Markup language by Tim Berners-Lee (1989)
ANSWER: B
Python is a high-level, interpreted programming language created by Guido van Rossum and first released in 1991.
Q2 Which of the following is a valid Python variable name? ▾
A) 2var
B) var-name
C) _var2
D) for
ANSWER: C
Variable names can start with a letter or underscore, cannot start with a digit, cannot contain hyphens, and cannot be keywords.
Q3 What is indentation in Python? ▾
A) Optional formatting with no functional use
B) It defines code blocks; wrong indentation raises an error
C) It is only required for functions
D) It is used to write comments
ANSWER: B
Python uses indentation to define blocks of code. Incorrect indentation causes an IndentationError.
Q4 Which of the following is the identity operator in Python? ▾
A) in
B) is
C) and
D) +
ANSWER: B
Identity operators (is, is not) check if two variables refer to the same object in memory.
UNIT 2: STRINGS
Q5 What is the difference between find() and index() in strings? ▾
A) find() returns -1 if not found; index() raises ValueError
B) index() returns -1 if not found; find() raises ValueError
C) Both raise ValueError if not found
D) Both return -1 if not found
ANSWER: A
find() returns -1 when the substring is absent, while index() throws a ValueError.
Q6 What is the difference between isdigit() and isnumeric()? ▾
A) isdigit() supports fractions; isnumeric() does not
B) isnumeric() supports fractions/roman numerals; isdigit() only 0-9
C) Both are identical
D) isdigit() checks alphabets
ANSWER: B
isdigit() is True only for digits 0-9; isnumeric() is True for numeric characters like fractions.
UNIT 3: LISTS
Q7 What is the difference between sort() and sorted()? ▾
A) sort() returns new list; sorted() modifies original
B) sorted() returns new list; sort() modifies original in-place
C) Both modify the original list
D) Both return new lists
ANSWER: B
list.sort() sorts in-place and returns None; sorted() returns a new list.
Q8 What is the difference between remove() and pop()? ▾
A) remove() deletes by index; pop() deletes by value
B) pop() deletes by index (returns value); remove() deletes by value
C) Both delete by index
D) Both delete by value
ANSWER: B
remove(x) deletes the first occurrence of value x; pop(i) removes and returns the element at index i (last by default).
UNIT 4: TUPLES
Q9 What is the difference between a tuple and a list? ▾
A) Tuples are mutable; lists are immutable
B) Lists are mutable; tuples are immutable
C) Tuples use []; lists use ()
D) Both are mutable
ANSWER: B
Lists can be modified after creation, while tuples cannot be changed.
Q10 Why cannot you modify or delete elements from a tuple? ▾
A) Tuples are mutable but restricted
B) Tuples are immutable; modification raises TypeError
C) Modification is allowed, deletion is not
D) Deletion is allowed, modification is not
ANSWER: B
Tuples are immutable, so any attempt to change or delete elements raises a TypeError.
UNIT 5: DICTIONARIES
Q11 What is the difference between a dictionary and a list? ▾
A) Lists are key-value pairs; dictionaries are ordered sequences
B) Dictionaries are key-value pairs; lists are indexed sequences
C) Both use key-value pairs
D) Both are indexed by position
ANSWER: B
Lists store ordered items by index; dictionaries store data as key-value pairs.
Q12 What is a KeyError in a dictionary? ▾
A) Error when accessing a non-existent key directly
B) Error when adding a new key
C) Error when using the in operator
D) Error when using get()
ANSWER: A
Accessing a missing key with dict[key] raises KeyError.
Q13 What is the advantage of the get() method? ▾
A) It raises KeyError if key is missing
B) It returns None/default instead of raising an error
C) It adds the key if missing
D) It modifies the key value automatically
ANSWER: B
dict.get(key, default) returns default when the key is not found, avoiding KeyError.
UNIT 6: CONTROL STATEMENTS
Q14 What is the difference between break and continue? ▾
A) break skips iteration, continue exits loop
B) continue skips iteration, break exits the loop
C) Both exit the loop
D) Both skip the current iteration
ANSWER: B
break ends the loop completely; continue skips the current iteration and moves to the next.

UNIT 1: PYTHON BASICS
S1 What are the applications of Python? ▾
ANSWER
Python is used in web development, data science, machine learning, automation, scripting, game development, and desktop apps.
S2 What are the two ways to run a Python program? Explain with examples. ▾
ANSWER
Interactive mode: Run python in terminal and type commands, e.g., print("Hello").
Script mode: Save code in a .py file and run: python file.py.
S3 What are comments in Python? Explain single-line and multi-line comments with examples. ▾
ANSWER
Comments are non-executable notes.
Single-line: # This is a comment
Multi-line: '''This is a multi-line comment''' or """This is a multi-line comment"""
S4 How do you assign a single value to multiple variables and multiple values to multiple variables? ▾
ANSWER
Single value: x = y = z = 10
Multiple values: a, b, c = 1, 2, 3
S5 What are data types in Python? Explain int, float, complex, and string with examples. ▾
ANSWER
int: 10, float: 10.5, complex: 3+4j, string: "Hello".
S6 What is type conversion? Explain int(), float(), and str() with examples. ▾
ANSWER
Type conversion changes a value's data type: int("10") -> 10, float("10.5") -> 10.5, str(10) -> "10".
UNIT 2: STRINGS
S7 How are strings declared in Python? ▾
ANSWER
Strings can use single quotes 'text', double quotes "text", or triple quotes '''text''' for multi-line.
S8 Explain string indexing and negative indexing with an example. ▾
ANSWER
For s = "Python", s[0] -> 'P'. Negative index counts from end: s[-1] -> 'n'.
S9 Explain string operators (+, *, [], [:], in, not in, r, %) with examples. ▾
ANSWER
+: "Hi" + "All" -> "HiAll"
*: "Hi" * 3 -> "HiHiHi"
[]: s[0] -> first char
[:]: s[1:4] -> substring
in/not in: "Py" in "Python" -> True
r: r"\n" keeps backslash literal
%: "Hello %s" % "World" -> "Hello World"
UNIT 3: LISTS
S10 What is a list in Python? How is it created? Give examples. ▾
ANSWER
A list is an ordered, mutable collection. Example: my_list = [1, 2, 3], empty: [].
S11 Explain list indexing and negative indexing with examples. ▾
ANSWER
my_list = [10, 20, 30]; my_list[0] -> 10, my_list[-1] -> 30.
S12 How do you update/change elements in a list? Give example. ▾
ANSWER
Use indexing: nums = [1, 2, 3]; nums[1] = 20 -> [1, 20, 3].
S13 How do you delete elements from a list using del? Give example. ▾
ANSWER
nums = [1, 2, 3]; del nums[1] -> [1, 3].
S14 How do you iterate a list using a for loop? ▾
ANSWER
for item in my_list: print(item)
UNIT 4: TUPLES
S15 How is a tuple created? Give examples including an empty tuple and a single-element tuple. ▾
ANSWER
tuple1 = (1, 2, 3), empty = (), single = (5,)
S16 Explain tuple indexing and negative indexing. ▾
ANSWER
t = (10, 20, 30); t[0] -> 10, t[-1] -> 30.
S17 Explain tuple operators (+, *, [], [:], in, not in) with examples. ▾
ANSWER
+: (1,2) + (3,4) -> (1,2,3,4)
*: (1,) * 3 -> (1,1,1)
[]: t[0] -> first item
[:]: t[1:3] -> slice
in/not in: 2 in (1,2,3) -> True
S18 How do you delete an entire tuple using del? ▾
ANSWER
t = (1, 2, 3); del t removes the tuple completely.
S19 How do you iterate a tuple using a for loop? ▾
ANSWER
for item in my_tuple: print(item)
UNIT 5: DICTIONARIES
S20 How do you create a dictionary? Give examples including an empty dictionary. ▾
ANSWER
my_dict = {"name": "Alice", "age": 25}; empty dict = {}.
S21 How do you access, add, and update values in a dictionary? ▾
ANSWER
Access: d["name"]. Add: d["city"] = "NY". Update: d["age"] = 26.
S22 How do you loop through a dictionary using a for loop? ▾
ANSWER
for key in d: print(key). To loop values: for val in d.values(): print(val).
S23 Explain keys(), values(), and items() methods of a dictionary with examples. ▾
ANSWER
d.keys() returns all keys, d.values() returns values, d.items() returns (key, value) pairs.
S24 How do you use two iteration variables with items() while looping? Give example. ▾
ANSWER
for key, value in d.items(): print(key, value)
UNIT 6: CONTROL STATEMENTS
S25 Explain if, if-else, and if-elif-else statements with syntax and examples. ▾
ANSWER
if: if condition: code
if-else: if cond: code1 else: code2
if-elif-else: if cond1: code1 elif cond2: code2 else: code3
S26 Explain the while loop with syntax and example. ▾
ANSWER
while condition: code. Example: i=0; while i<3: print(i); i+=1
S27 How is the else block used with a while loop? Give example. ▾
ANSWER
The else block runs if the loop finishes normally (no break). Example: while i<3: ... else: print("Done").
S28 Explain the for loop with syntax and example. What is range()? ▾
ANSWER
for item in sequence: code. Example: for i in range(3): print(i). range() generates numbers from start to stop-1.
S29 How is the else block used with a for loop? Give example. ▾
ANSWER
The else block runs if the loop finishes without break. Example: for i in range(3): ... else: print("Done").
S30 Explain break and continue statements with syntax and examples. ▾
ANSWER
break exits the loop; continue skips to next iteration. Example: if i==3: break; if i==2: continue.

▦ Long Questions

7 questions — detailed answers with examples

UNIT 1: PYTHON BASICS
L1 List and explain any five features of Python. ▾
ANSWER
  • Interpreted: Runs line by line without compilation.
  • High-level: Easy syntax close to natural language.
  • Dynamically typed: No need to declare variable types.
  • Portable: Runs on different operating systems.
  • Large standard library: Many built-in modules and functions.
L2 Explain all types of operators in Python with examples. ▾
ANSWER
  • Arithmetic: +, -, *, /, %, //, **. Example: 10 // 3 = 3.
  • Comparison: ==, !=, >, <, >=, <=. Example: 5 > 3 -> True.
  • Assignment: =, +=, -=, *=. Example: x += 2.
  • Logical: and, or, not. Example: (5 > 3) and (2 < 4).
  • Bitwise: &, |, ^, ~, <<, >>. Example: 5 & 3 = 1.
  • Membership: in, not in. Example: 2 in [1,2,3] -> True.
  • Identity: is, is not. Example: a is b.
UNIT 2: STRINGS
L3 Write short notes on string methods with syntax and examples. ▾
ANSWER
  • len(s): len("Hello") -> 5
  • lower(): "HELLO".lower() -> "hello"
  • upper(): "hello".upper() -> "HELLO"
  • replace(): "Hello".replace("H","J") -> "Jello"
  • split(): "a,b".split(",") -> ["a","b"]
  • find(): "Hello".find("l") -> 2
  • index(): "Hello".index("l") -> 2
  • isalnum(): "Hello123".isalnum() -> True
  • isdigit(): "123".isdigit() -> True
  • isnumeric(): "1/2".isnumeric() -> False
  • islower(): "hello".islower() -> True
  • isupper(): "HELLO".isupper() -> True
UNIT 3: LISTS
L4 Explain list functions and methods with syntax and examples. ▾
ANSWER
  • len(list): len([1,2,3]) -> 3
  • max(list): max([1,2,3]) -> 3
  • min(list): min([1,2,3]) -> 1
  • sum(list): sum([1,2,3]) -> 6
  • list(iterable): list((1,2)) -> [1,2]
  • sorted(list): sorted([3,1,2]) -> [1,2,3]
  • append(x): a.append(3)
  • remove(x): a.remove(2)
  • sort(): a.sort()
  • reverse(): a.reverse()
  • count(x): a.count(1)
  • index(x): a.index(2)
  • insert(i,x): a.insert(1, 9)
  • pop(i): a.pop(0)
  • clear(): a.clear()
UNIT 4: TUPLES
L5 Explain tuple functions and methods with syntax and examples. ▾
ANSWER
  • len(t): len((1,2,3)) -> 3
  • max(t): max((1,2,3)) -> 3
  • min(t): min((1,2,3)) -> 1
  • sum(t): sum((1,2,3)) -> 6
  • tuple(iterable): tuple([1,2]) -> (1,2)
  • sorted(t): sorted((3,1,2)) -> [1,2,3]
  • count(x): (1,2,1).count(1) -> 2
  • index(x): (1,2,3).index(2) -> 1
UNIT 5: DICTIONARIES
L6 Write a Python program to count the frequency of words in a sentence using a dictionary. ▾
ANSWER
sentence = "hello world hello python"
words = sentence.split()
freq = {}

for w in words:
  freq[w] = freq.get(w, 0) + 1

print(freq)
UNIT 6: CONTROL STATEMENTS
L7 Write a Python program to find the maximum of three numbers using if-elif-else. ▾
ANSWER
a = 10
b = 20
c = 15

if a >= b and a >= c:
  max_num = a
elif b >= a and b >= c:
  max_num = b
else:
  max_num = c

print("Maximum is:", max_num)
